# Plan: Working .deb package for YACReader (TDD)

## Goal

Produce a working `.deb` package of YACReader (version from `VERSION`, currently `10.6.0`)
that installs and runs on **this system**: Linux Mint 22.3 ("Zena") — a Ubuntu 24.04
(noble) base with distro Qt 6.4.2, distro poppler 24.02 and the distro `7zip` runtime.

Starting point: `build_scripts/ubuntu_24.04/` — its build config is mirrored:
Qt 6, `DECOMPRESSION_BACKEND=7zip` (RAR5 capable `7z.so` shipped by the package),
`PDF_BACKEND=poppler`.

## Test-first approach (e2e)

The e2e test is written **before** any packaging code, and must fail first:

`build_scripts/ubuntu_24.04/e2e_deb_test.sh`

It verifies, in order:

1. **Package sanity** — a `.deb` exists in `build_scripts/ubuntu_24.04/dist/`,
   `dpkg-deb --info` parses it, package name `yacreader`, version matches `VERSION`.
2. **Install** — `apt-get install ./dist/yacreader_*.deb` succeeds
   (auto-resolves dependencies), `dpkg -s yacreader` reports `installed`.
3. **Files present** — the three binaries (`/usr/bin/YACReader`,
   `/usr/bin/YACReaderLibrary`, `/usr/bin/YACReaderLibraryServer`), desktop files,
   icons, man pages, server web assets and the bundled `/usr/lib/*/yacreader/7z.so`.
4. **Runs without crashing (headless)** — each of these must exit 0, no SIGSEGV:
   - `YACReaderLibraryServer --version`
   - `YACReaderLibraryServer --system-info`
   - `YACReaderLibraryServer list-libraries` (isolated `HOME`/`XDG_*`)
   - `QT_QPA_PLATFORM=offscreen YACReader --help`
   - `QT_QPA_PLATFORM=offscreen YACReaderLibrary --help`
5. **Real startup** — `QT_QPA_PLATFORM=offscreen YACReader <sample.cbz>` is left
   running for ~5 s: process must still be alive (i.e. the GUI started, archive
   opened through the 7zip backend) and is then terminated cleanly.
6. **Uninstall** — `apt-get remove -y yacreader` leaves no binaries behind and
   `dpkg -s yacreader` reports the package as removed.

A fixture `sample.cbz` (zip of tiny PNG pages) is generated by the test itself.

## Packaging design

* `debian/` directory (debhelper compat 13, `dpkg-buildpackage -b` from the repo root).
* `debian/rules`: `dh` + `dh_auto_configure` with
  `-DDECOMPRESSION_BACKEND=7zip -DPDF_BACKEND=poppler -DBUILD_TESTS=ON`
  (hardening flags enabled). CMake install rules already place binaries, desktop
  files, icons, man pages and `release/server` web assets correctly.
* Single binary package `yacreader` containing all three apps.
* `7z.so`: the package installs the in-tree bundled
  `dependencies/7zip/linux/x86_64/7z.so` (from `yacreader-7z-deps`, full format set
  incl. RAR5) to `${LIBDIR}/yacreader/7z.so`, which is the first path the app checks
  at runtime (`YACReader::load7zLibrary()`), so RAR support needs no external
  `7zip`/`p7zip` package.
* `Depends`: computed shared-lib deps via `${shlib:Depends}` (Qt 6, poppler,
  libarchive is *not* used) plus QML runtime modules that shlibdeps cannot detect:
  `qml6-module-qtquick-controls`, `qml6-module-qtquick-layouts`,
  `qml6-module-qt5compat-graphicaleffects`, `qml6-module-qtqml-workerscript`,
  `qml6-module-qtquick-window`, `qt6-image-formats-plugins`,
  `qt6-qpa-plugins`.
* Build deps: from `build.sh` translated to dev packages (qt6-base-dev,
  qt6-declarative-dev, qt6-multimedia-dev, qt6-tools-dev(+tools), libqt6svg6-dev,
  libqt6core5compat6-dev, libpoppler-qt6-dev, ...) plus debhelper.
* `build_scripts/ubuntu_24.04/build_deb.sh` orchestrates:
  1. install build dependencies via apt,
  2. pre-fetch the 7zip 23.01 source into `compressed_archive/lib7zip`
     (same archive as `build.sh`; also fetched automatically by CMake FetchContent
     if missing),
  3. `dpkg-buildpackage -us -uc -b`,
  4. copy the produced `.deb` into `build_scripts/ubuntu_24.04/dist/`.

## Non-goals

* No upload/PPA packaging, no source `.dsc`/`.orig.tar` workflow (binary-only build).
* No AppImage/Flatpak, no bundling of Qt (we use the distro Qt 6.4).
* No `BUILD_SERVER_STANDALONE` (the GUI library app is included, matching upstream).
